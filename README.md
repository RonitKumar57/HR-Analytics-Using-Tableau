#  💼 HR Analytics Dashboard (Tableau) :

This Tableau dashboard visualizes HR data to uncover key workforce trends. It explores attrition rates, employee demographics, department and education-wise attrition, job satisfaction levels, and more.

# 🔍 Key Features :

1.  Attrition rate breakdown by department, gender, and age group.

2.  Employee distribution across age ranges.

3.  Education field-wise attrition comparison.

4.  Job satisfaction ratings by role.

5.  Interactive filtering by education level.

#### The dashboard provides actionable insights to help HR teams identify areas of concern and improve employee retention.
